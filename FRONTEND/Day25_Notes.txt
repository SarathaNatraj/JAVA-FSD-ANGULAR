SPA - Single Page Applications
	-  Front End frameworks supports SPA
	- 
Angular - front end frameworks developed by Google
		- Gmail, Google cloud console, Microsoft Office Online, Airbnb 
		- full fledged house
		- if you need complete, structured framework - choose Angular

React - JS library building UI developed by Meta 
	 - js components
	 - ts components 
	 - modern house only structure is available, on top of this you have to construct UI
	 Facebook, Instagram, Netflix
	 - if you need flexibility, speed and huge ecosystem - choose React
	 
	 
Steps to create angular project
	1. Install Angular cLi as globally we need to do it for one-time
		npm install -g @angular/cli 
	2. Create a angular project	ng - node generate 
		ng new my-angular-app
		PRESS -> ENTER,
				 NO
				 YES
		then project will be created
	3. package.json
		scripts section
			ng build -> build your front end code - similar mvn install
			ng serve -> start the your angular app - similar run as Java Application
			ng test -> run test scripts - similar mvn test
				 
	4. Angular component  consists of 4 files
			.html - templates
			.css - styles
			.ts - logic
			.spec.ts - test case file for the component
	5. Generate component		
			ng g c <component_name>
			Add this component in app.ts
				imports section
			Add this component in app.html
				<app-component-name></app-component-name>
				
	6. Routing
			http://localhost:4200/hello - Hello 
			http://localhost:4200/welcome - Welcome
			
			Adding the routing app.routes.ts -> define the routes there
				export const routes: Routes = [
					{path:'hello', component:Hello},
					{path:'welcome', component:Welcome}
				];
			and app.html change the code like this 
				<nav>
					<a  href="/hello">Hello Page</a> <br/>
					<a href="/welcome">Welcome Page</a>
				</nav>
				<router-outlet />

5. Connect with back-end code
			create interface -> Customer 
			create service class - "ng g s <service_name>"
					will generate only component.ts class and component.spec.ts
					pure front end logic , this does nt require UI
					
			for this (ngSubmit), [(ngModel)] for data binding -  import FormsModule in app.ts 
			for making http request to backend - import HttpClientModule in app.ts
			
			main.ts replace this code
				import { bootstrapApplication } from '@angular/platform-browser';
				import { importProvidersFrom } from '@angular/core';
				import { HttpClientModule } from '@angular/common/http';

				import { App } from './app/app';
				import { appConfig } from './app/app.config';

				bootstrapApplication(App, {
				  ...appConfig,
				  providers: [
					...appConfig.providers || [],
					importProvidersFrom(HttpClientModule)  // ✅ Add this line
				  ]
				})
				  .catch((err) => console.error(err));
				  
		

			add-customer.html 
				-> bind each property with [(ngModel)] = customer.name
				-> on button click  (click)="onSubmit()"
			add-customer.ts -> define onSubmit function
				-> call customerservice class method to save the customer
				
			view-customer.ts
				-> class implements OnInit interface
				-> ngOnInit method should be overridden
				-> call customerservice.getCustomers 
				-> map the reult of getCustomers to customers array
			view-customer.html
				-> table iterate customers array 
				->  <tr *ngFor="let customer of customers">
