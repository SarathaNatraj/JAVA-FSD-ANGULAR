Structural directives - shaping or modifying DOM structure
	1. *ngIf -> conditionally rendered divs
	2. *ngFor -> iterate the data
	3. *ngSwitch -> multiple conditions to show different UI parts
Attribute Directives - change appearance or behavior of DOM elements
	1.	ngClass - add/remove class - style class is declared in css
	2.	ngStyle - set inline styles dynamically 
	3.  ngModel - this perfoms two-way data binding -> requires FormsModule
