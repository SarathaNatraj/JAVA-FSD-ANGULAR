	Some builtin directives
	Directives - spl instructions in the DOM that angular is going to do something with an element, component or attribute
		change the appearance -> ngStyle or 
		change the behaviour - 
	3 types of Directives:-
		Component Directives -> selector attribute in @Component annotation
		Structural Directives - ngIf, ngFor, ngSwitch
		Attribute Directives - ngStyle, ngClass, 
		
		custom directives - is possible
		
		ngFor
		
		<ng-template ngFor = "let customer of customers">
			<div>{{customer.name}}</div>
		</ng-template>
		
		<div *ngFor="let customer of customers" class="customer-row">
			<div>{{ customer.id }}</div>
		</div>

	HttpClient -> builtin service for making the Http Requests(GET,POST, DELETE, etc..)
		1. app.ts
			Import HttpClientModule 
		2. provider has to be added in app.config.ts
			provideHttpClient()
		3. main.ts 
			bootstrapApplication(App, {
				...appConfig,
				providers: [
				...appConfig.providers || [],
					importProvidersFrom(HttpClientModule)  // ✅ Add this line
				]
			})
		4. Inject HttpClient in your service
			make your service/backend calls
